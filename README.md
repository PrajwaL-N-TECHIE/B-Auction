# B-Auction • Real-Time Interactive Bidding & Draft Arena

A multiplayer live bidding arena for sports leagues, fantasy drafts, hackathons, and charity auctions with real-time mobile bidding, gavel timer, and stage projector display by Buildicy.

## Key Features
- **Live WebSocket Bidding**: Instant sub-50ms synchronization powered by Supabase Realtime channels.
- **Franchise & Purse Tracking**: Automatic budget checks, real-time purse balance deductions, and team squad manager.
- **Preloaded Auction Packs**: Premier Cricket (IPL Style), Tech Unicorn Dream Team, and Sci-Fi Artifacts.
- **Auditorium Stage Projector Mode**: Full-screen stage view with high-contrast QR code, live price ticker, and celebratory sold fanfares.
- **Tactile Sound Effects**: Custom Web Audio API acoustic gavel strikes, bid chimes, countdown ticks, and fanfare.
- **Responsive Dark & Light Themes**: High-contrast, accessibility-checked theme switching.

## Development
```bash
npm install
npm run dev
```

Built with React 19, TypeScript, Vite, Tailwind CSS v4, and Supabase.
